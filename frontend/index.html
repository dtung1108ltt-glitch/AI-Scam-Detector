DAA Crypto Market

Dữ liệu thị trường thật từ daathena.com — phát hiện giả mạo token, kiểm tra giá thật

Chưa kết nối
❌ Lỗi kết nối
Lỗi "Host not in allowlist" — DAA API chặn IP chưa được đăng ký.
Chọn 1 trong 2 cách dưới:
✅ Cách 1 — Whitelist IP (0 code)
  1. Vào DAA Settings → API Keys
  2. Chỉnh sửa API key của bạn
  3. Tìm ô IP Whitelist
  4. Thêm IP server/máy tính của bạn
  5. Nhấn Test kết nối lại
IP hiện tại của bạn: đang lấy...
⚡ Cách 2 — Proxy Server (local)
  1. Tải file daa-proxy-server.js
  2. Chạy: npm i express cors && node daa-proxy-server.js
  3. Điền http://localhost:3001/proxy vào ô Proxy URL bên trên
  4. Nhấn Test kết nối lại
Proxy server chưa chạy hoặc sai URL.
Mở terminal và chạy: node daa-proxy-server.js rồi đảm bảo Proxy URL là http://localhost:3001/proxy
